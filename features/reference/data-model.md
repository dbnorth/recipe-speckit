# Data Model Reference

**Status:** current on `dev` after Features 1–5.

Sequelize models in `backend/app/models/`. IDs are integer PKs generated by the database. `createdAt` / `updatedAt` are Sequelize timestamps on every table.

## Tables

### users

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK | Feature 1 |
| firstName | string | required | Feature 1 |
| lastName | string | required | Feature 1 |
| email | string | required; uniqueness enforced in the register controller (not a DB unique index) | Feature 1 |
| password | blob | required, hashed | Feature 1 |
| salt | blob | required | Feature 1 |

### sessions

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK; encrypted id is the client token | Feature 1 |
| email | string | required | Feature 1 |
| userId | integer | FK → users | Feature 1 |
| expirationDate | datetime | required; login/register sets now + 1 day | Feature 1 |

### recipes

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK | Feature 2 |
| name | string | required | Feature 2 |
| description | string | required | Feature 2 |
| servings | integer | required | Feature 2 |
| time | integer | required (minutes) | Feature 2 |
| isPublished | boolean | required | Feature 2 |
| userId | integer | FK → users | Feature 2 |

### ingredients

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK | Feature 3 |
| name | string | required | Feature 3 |
| unit | string | required | Feature 3 |
| pricePerUnit | decimal(10,2) | required on create | Feature 3 |

No `userId` — shared catalog.

### recipeSteps

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK | Feature 4 |
| stepNumber | integer | required | Feature 4 |
| instruction | string(5000) | required | Feature 4 |
| recipeId | integer | FK → recipes | Feature 4 |

### recipeIngredients

| Field | Type | Rules | Introduced |
|-------|------|--------|------------|
| id | integer | PK | Feature 4 |
| quantity | float | required | Feature 4 |
| recipeId | integer | FK → recipes | Feature 4 |
| recipeStepId | integer | FK → recipeSteps, nullable | Feature 4 |
| ingredientId | integer | FK → ingredients | Feature 4 |

---

## Associations

| Association | Notes | Introduced |
|-------------|-------|------------|
| User hasMany Session | `as: "session"` | Feature 1 |
| Session belongsTo User | `as: "user"` | Feature 1 |
| User hasMany Recipe | `as: "recipe"` | Feature 2 |
| Recipe belongsTo User | `as: "user"` | Feature 2 |
| Recipe hasMany RecipeStep | `as: "recipeStep"` | Feature 4 |
| RecipeStep belongsTo Recipe | `as: "recipe"` | Feature 4 |
| Recipe hasMany RecipeIngredient | `as: "recipeIngredient"` | Feature 4 |
| RecipeStep hasMany RecipeIngredient | `as: "recipeIngredient"` | Feature 4 |
| Ingredient hasMany RecipeIngredient | `as: "recipeIngredient"` | Feature 4 |
| RecipeIngredient belongsTo Recipe | `as: "recipe"` | Feature 4 |
| RecipeIngredient belongsTo RecipeStep | `as: "recipeStep"`; FK nullable | Feature 4 |
| RecipeIngredient belongsTo Ingredient | `as: "ingredient"` | Feature 4 |
